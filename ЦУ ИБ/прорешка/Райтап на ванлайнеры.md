## Мимолётные файлы

Для начала напишем базовую команду, которая будет выводить пары самого файла и его содержание:
`find /tmp/flag_parts -type f -exec sh -c 'echo "$1"; cat "$1"; echo' _ {} \;`
Теперь напишем бесконечный цикл с повторением каждую секунду:
`while :; command ; sleep 1; done`

Объединим конечный ванлайнер:
`while :; do find /tmp/flag_parts -type f -exec sh -c 'echo "$1"; cat "$1"; echo' _ {} \;; sleep 1; done`
