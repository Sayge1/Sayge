match case конструкция:
```python
a = input()

match a:
    case "a":
		print("1")
	case "b":
		print("2")
	case _:
		print("неизвестная команда")
```

match day:

Команды списков:
.extend(arr) - добавляет к списку другой список
.insert(i, x) - добавляет на индекс i элемент x и сдвигает все элементы справа от него вправо
.remove(x) - удаляет первое вхождение x
.pop(i) - удалить элемент по индексу (numba = arr.pop(i) позволяет получить удаленный элемент)
del arr[1:3] - позволяет удалить сразу несколько элементов, не возвращает значение
.clear - очищает список
.index(x) = возвращает индекс первого вхождения
.sort(Reverse = False, key = None) - отсортировать список
new_arr = sorted(arr) - получить отсортированную копию
.reverse() - перевернуть список

Команды строк:
.split(sep, maxsplit=) - разделение строки на список
separator.join(arr) - склеивает элементы через separator
.strip(x) - обрезает лишние символы x с обоих краев строки
.replace(old, new) - заменяет вхождения old на new в строке
.upper, .lower, .capitilize - меняет регистр букв
.find(substring) - ищет substring в строке и возвращает индекс первого вхождения, в ином случае возвращает -1
.count(substring) - считает количество вхождений substring в строку
.startswith(str), .endswith(str) - проверяет что строка начинается/заканчивается на str
.isdigit(), .isalpha(), .isalnum() - проверяет что строка это неотрицательное целое число/буквы/всё вместе

Словари:
```python
user = dict(name="Анна", age=20, city="Москва")
print(user)  # {'name': 'Анна', 'age': 20, 'city': 'Москва'}
```
dict(zip(arr1, arr2)) - zip связывает элементы 2 списков (типо биекция), и dict потом делает словарь
.get(key, default) - получает значение из словаря по ключу key, если не находит - возвращает default
.update(dict) - добавляет новый словарь к текущему
.setdefault(key, default) - если ключ есть в словаре - возвращает текущее значение по ключу, если нет - добавляет пару key:default и возвращает default
del dict[key] - удаляет значение по ключу
.pop(key, default) - удаляет значение по ключу и возвращает удаленное значение, либо возвращает default
.clear() - очистить словарь
.keys() - возвращает список ключей
.values() - возвращает список значений
for key, value in dict.items() - аналог enumerate
.items - возвращает список пар

Функции:
можно указывать аргументы как позиционно, так и явно через param=arg
также в def okak(x) можно указать базовое значение аргумента def okak(x=1)
`def okak(param1, param2, *args)` - args принимает любое количество аргументов и потом становится кортежем
`def okak(param1, param2, *kwargs)` - kwargs принимает любое количество именованных переменных (param=arg) и становится словарем

Глобальную переменную нельзя менять внутри функции просто так
global переменная - делает привязку к глобальной переменной внутри функции
nonlocal переменная - делает привязку к ближайшей внешней функции
