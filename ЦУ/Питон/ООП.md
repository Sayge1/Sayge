```python
class Product:
    """Базовый класс для всех товаров."""
    def __init__(self, name, price, stock):
        self.name = name
        self.price = price
        self.stock = stock

class Laptop(Product):
    """Ноутбук — наследует Product, добавляет диагональ и RAM."""
    def __init__(self, name, price, stock, screen_size, ram):
        super().__init__(name, price, stock)
        self.screen_size = screen_size
        self.ram = ram
```

Также если не надо добавлять новые характеристики класса - `__init__` у дочернего класса можно не писать

Переписывание родительской функции в дочернем классе:
```python
def display_info(self):
        """Расширенный вывод: сначала общая информация, потом характеристики."""
        super().display_info()  # Вызываем родительскую версию
        print(f"  Экран: {self.screen_size}\", RAM: {self.ram} ГБ")
```

также через super().display_info() в дочернем классе можно вызывать функцию родительского

Геттер и сеттер:
```python
@property
    def price(self):
        """Геттер: доступ через product.price"""
        return self._price

    @price.setter
    def price(self, new_price):
        """Сеттер: запись через product.price = значение"""
        if not isinstance(new_price, (int, float)):
            raise TypeError(f"Цена должна быть числом: {type(new_price).__name__}")
        if new_price < 0:
            raise ValueError(f"Цена не может быть отрицательной: {new_price}")
        self._price = new_price
        
# Чтение — выглядит как обращение к атрибуту, но вызывается геттер
print(laptop.price)  # 75000

# Запись — выглядит как присваивание, но вызывается сеттер
laptop.price = 69000
print(laptop.price)  # 69000
```

@staticmethod - не имеет доступа к классу или к экземпляру
@classmethod - имеет доступ только к атрибутам класса через cls

```python
def __str__(self):
	return f"{self.name}"
	
def __repr__(self):
    return f"Product('{self.name}', {self.price}, {self.stock})"

def __eq__(self, other):
	if not isinstance(other, Product):
		return False  # Нельзя сравнивать Product с числом или строкой
	return (self.name == other.name 
			and self.price == other.price)
```
