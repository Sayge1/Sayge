$||\vec{a}|| = \sqrt{a^2_1 + a^2_2 + ... + a^2_n}$ - длина вектора
$\hat{a} = \frac{\vec{a}}{||\vec{a}||}$ - получение единичного вектора из неединичного
При сложении и вычитании векторов их координаты складываются/вычитаются
при умножении вектора на число его координаты умножаются
$\vec{a} * \vec{b} = \langle \vec{a}, \vec{b} \rangle = a_1b_1 + a_2b_2 + ... + a_nb_n$   
$\vec{a} * \vec{b} = ||\vec{a}||||\vec{b}||cosO$ 
$cosO = \frac{\vec{a} * \vec{b}}{||\vec{a}||||\vec{b}||}$ 
если $\vec{a} * \vec{b} = 0$, то векторы перпендикулярны

Теорема косинусов в векторной форме:
$||\vec{a} - \vec{b}||^2 = ||\vec{a}||^2 + ||\vec{b}||^2 - 2||\vec{a}||||\vec{b}||cosO$

$cosO = \frac{||\vec{a}||^2 + ||\vec{b}||^2 - ||\vec{a} - \vec{b}||^2}{2||\vec{a}||||\vec{b}||}$
