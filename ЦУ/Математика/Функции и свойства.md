Если f(x) = f(-x) на всех x - то функция четная
Если -f(x) = f(-x) на всех x - то функция нечетная
Функция называется возрастающей на промежутке I, если для любого $x_1, x_2$ выполняется $f(x_1) < f(x_2)$
Функция называется убывающей на промежутке I, если для любого $x_1, x_2$ выполняется $f(x_1) > f(x_2)$

Многочлены - $f(x) = a_nx^n + a_{n-1}x^{n-1} + ... + a_1x + a_0$ , степень многочлена n
если a > 0, то ветви параболы вверх
если a < 0, то ветви параболы вниз

Степенная функция $f(x) = x^n$, если n = 2, 4 и т.д. то ветви будут зеркальны относительно оси x

Тригонометрические функции:
sin(x) - из y=0, справа ветвь вверх, слева вниз
cos(x) - из y=1, обе ветви вниз
tg(x) - из y=0, справа ветвь вверх, слева вниз. Каждые P/2 асимптота

Показательная функция:
$f(x) = a^x$
0 < a < 1 - функция убывает при возрастании x
a > 1 - функция возрастает при возрастании x

Композиция функции $f \circ g = f(g(x))$
Обратная функция $f^{-1}(x)$ находится решением $y = f(x)$ и последующим представлением y через x
