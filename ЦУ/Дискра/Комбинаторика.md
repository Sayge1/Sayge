Сочетание - это комбинация, где порядок не важен
Размещение - это комбинация, где порядок важен

**Порядок важен**:
**Размещения**:
Теор 1: Количество размещений с повторениями из n по k равно $n^k$ 
Теор 2: Количество размещений без повторений из n по k равно $\frac{n!}{(n-k)!}$

**Перестановки**(k = n):
Теор 3: Количество перестановок на n элементах равно $n!$
Число перестановок с повторениями — это количество способов составить упорядоченную последовательность длины n из элементов множества {1, ..., k}, в которой элемент 1 будет встречаться ровно $n_1$ раз, элемент 2 будет встречаться ровно $n_2$ раз, ..., элемент k будет встречаться ровно $n_k$ раз:
$P_n(n_1,n_2,...,n_k) = \frac{n!}{n_1!n_2!...n_k!}$

В "хороводе" количество перестановок равно $\frac{n!}{n}$
в "ожерелье" количество перестановок равно $\frac{n!}{2n}$

**Порядок не важен**:
**Сочетания**:
Сочетание: $C_n^k = \frac{n!}{k!(n-k)!}$ (порядок не важен, все элементы уникальные)
Сочетание с повторениями: $\overline{C}_n^k = \frac{(n+k-1)!}{k!(n-1)!}$ (порядок не важен, элементы не обязательно уникальные)
