Формулы:
mean = сумма элементов / количество элементов
med = если нечетное - $X_{i+1/2}$ , если четное - $(X_{i/2} + X_{i/2 + 1}) / 2$
Размах = максимальный элемент - минимальный
Мода = самый частый элемент
Дисперсия = $D = \frac{\sum (x_i - \bar{x})^2}{N}$  
Стандартное отклонение = $std = \sqrt{\frac{\sum (x_i - \bar{x})^2}{N}}$  
Квантиль = $Q_q = x_{\lfloor i \rfloor} + (i - \lfloor i \rfloor)* (x_{\lceil i \rceil} - x_{\lfloor i \rfloor})$
$i = 1 + (n - 1)q$
Межквантильный размах = $IQR = Q_3 - Q_1$
