
> [!NOTE]- Обозначения
> TR - общая выручка
> TC - общие издержки
> TP - общее производство
> MP - предельный продукт 
> L - количество ресурсов (обычно кол. работников)
> VC - переменные издержки
> FC - постоянные издержки
> Q - количество выпущенной продукции


Прибыль фирмы:
$\pi = TR - TC$ (общая выручка - общие издержки)
Существует 3 основных способа увеличения прибыли: улучшение производства, издержек и продаж

Производственная функция:
$TP = f(L, K,...)$
$TP$ - объем выпуска
$L$ - количество использованных трудовых ресурсов
$L$ - объем капитальных ресурсов

$SR$ - за короткий период компания не может изменить объем использования своих ресурсов
$LR$ - за долгий период компания может поменять использование своих ресурсов

$MP_L = \frac{\Delta TP}{\Delta L}$ - Прирост выпуска на одну единицу труда 
$MP_K = \frac{\Delta TP}{\Delta K}$
$AP_L = \frac{TP}{L}$ - средняя продукция на сотрудника
$AP_K = \frac{TP}{K}$ - средняя продукция на единицу капитала
Максимальная производительность труда достигается при максимуме среднего продукта $AP_L$, на пересечении $MP_L$ и $AP_L$.
Средний продукт растет пока он меньше предельного $AP_L < MP_L$
$MP = \frac{TP}{L} = AP$ - в точке максимума $AP$

Явные издержки - легко наблюдать, например цена аренды помещения
Альтернативные издержки - зачастую сложно наблюдать, связаны с использованием имущества фирмы

Бухгалтерские издержки - сумма всех явных издержек фирмы
Экономические издержки - сумма явных и альтернативных издержек
Бухгалтерская прибыль - разность выручки и бухгалтерских издержек
Экономическая прибыль - разность выручки и экономических издержек

$TC = VC + FC$ - общие издержки
$ATC = TC/Q$ - средние общие издержки
$TR = P * Q$ - общая выручка
$AVC = \frac{VC}{Q}$ - средние переменные издержки
$AFC = \frac{FC}{Q}$ - средние постоянные издержки
$ATC = AVC + AFC$
