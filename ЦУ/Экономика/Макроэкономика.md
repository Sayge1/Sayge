$E = C + I + G + (Ex - Im) = C + I + G + X_n$
$E = Y$
$Y^d = Y - Tx + Tr = Y - (Tx - Tr) = Y - T$
$Y^d = C + S$
$C + S = Y - Tx + Tr$
$Y = C + S + Tx - Tr$
$C + I + G + (Ex - Im) = C + S + Tx - Tr$
$I + G + Ex + Tr = S + Tx + Im$
$X_n = Ex - Im$
$T = Tx - Tr$
$Y^d = Y - T$
$S = Y^d - C$
$E = C + I + G + X_n$

$E$ — совокупные расходы в экономике
$Y$ — совокупный доход (ВВП)
$Y^d$ — располагаемый доход домохозяйств
$C$ — потребительские расходы
$I$ — инвестиционные расходы
$G$ — государственные закупки товаров и услуг
$Ex$ — экспорт
$Im$ — импорт
$X_n$ — чистый экспорт
$Tx$ — налоги
$Tr$ — государственные трансферты
$T$ — чистые налоги
$S$ — сбережения домохозяйств
