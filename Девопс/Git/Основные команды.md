git init - если в папке нет .git создаёт git репозиторий
git status - посмотреть статус репозитория
git add файл - добавляет файл в репозиторий и начинает отслеживать его (другими словами файл попадает в индекс)
git commit -m сообщение - коммит

git config --global core.quotepath false - делает так чтобы файлы с кириллицей нормально выводились
