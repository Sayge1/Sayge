## Задание 4

А. $\overline{X} = \frac{K}{N}$
Б. K - да
N - всего
$V_x =  \frac{\sum_{i=1}^n(x_i - \overline{x})^2}{N}$
$x_i = 0 \implies (-\frac{K}{N})^2$
$(N-K)\frac{K^2}{N^2} = \frac{K^2}{N} - \frac{K^3}{N^2}$
$x_i = 1 \implies K(1 - \frac{K}{N})^2 = K(1 - \frac{2K}{N} + \frac{K^2}{N^2}) =$
$= K - \frac{2K^2}{N} + \frac{K^3}{N^2}$
$V_X = \frac{\frac{K^2}{N} - \frac{K^3}{N^2} + K - \frac{2K^2}{N} + \frac{K^3}{N^2}}{N} = \frac{K - \frac{K^2}{N}}{N} = \frac{K}{N} - \frac{K^2}{N^2}$
$\delta_X = \sqrt{\frac{K}{N} - \frac{K^2}{N^2}}$
В. дисперсия ответов минимальна при K = 0 и K = N. Соответственно дисперсия минимальна когда все участники дают одинаковый ответ (все "нет" или все "да").
Г. Возьмём производную по K и найдём экстремум:
$V'(K) = \frac{1}{N} - \frac{2K}{N^2}$
$\frac{1}{N} - \frac{2K}{N^2} = 0$
$N - 2K = 0$
$-2K = -N$
$K = \frac{N}{2}$
возьмём вторую производную
$V''(K) = -\frac{2}{N^2}$
$V''(K) < 0$
Значит найденная точка максимум
$V_{max} = \frac{\frac{N}{2}}{N} - \frac{(\frac{N}{2})^2}{N^2} = \frac{1}{2} - \frac{1}{4} = \frac{1}{4}$
$\delta_{max} = \sqrt{\frac{1}{4}} = \frac{1}{2}$
Ответ: $K = \frac{N}{2}$, $\delta_{max} = \frac{1}{2}$

## Задание 5

А. $N = n_a + n_b$
$\overline{X} = \frac{\sum_{i=1}^{n_a} a_i + \sum_{j=1}^{n_b} b_j}{n_a + n_b}$
$\sum_{i=1}^{n_a} a_i = n_a \overline{X_a}$
$\sum_{j=1}^{n_b} b_j = n_b\overline{X_b}$
$\overline{X} = \frac{n_a \overline{X_a} + n_b\overline{X_b}}{n_a + n_b}$
$\delta_{общ}^2 = \frac{\sum_{i=1}^{n_a} (a_i - \overline{X})^2 + \sum_{j=1}^{n_b} (b_j - \overline{X})^2}{n_a + n_b}$
Б. $a_i - \overline{X} = (a_i - \overline{X_a}) + (\overline{X_a} - \overline{X})$
$\sum_{i=1}^{n_a}(a_i - \overline{X_a}) = 0$
$\sum_{i=1}^{n_a}(a_i - \overline{X})^2 = \sum_{i=1}^{n_a}(a_i - \overline{X_a})^2 + n_a(\overline{X_a} - \overline{X})^2$
$\sum_{i=1}^{n_a}(a_i - \overline{X_a})^2 = n_a \delta^2$
$\sum_{i=1}^{n_a}(a_i - \overline{X})^2 = n_a \delta^2 + n_a(\overline{X_a} - \overline{X})^2$
$\sum_{j=1}^{n_b}(b_j - \overline{X})^2 = n_b \delta^2 + n_b(\overline{X_b} - \overline{X})^2$
$\delta_{общ}^2 = \frac{n_a \delta^2 + n_a(\overline{X_a} - \overline{X})^2 + n_b \delta^2 + n_b(\overline{X_b} - \overline{X})^2}{n_a + n_b}$
$\delta_{общ}^2 = \delta^2 + \frac{n_a(\overline{X_a} - \overline{X})^2 + n_b(\overline{X_b} - \overline{X})^2}{n_a + n_b}$
$\delta_{общ}^2 = \delta^2 + \frac{n_an_b}{(n_a + n_b)^2}(\overline{X_a} - \overline{X_b})^2$
В. $\delta^2$ - разброс внутри групп
$\frac{n_an_b}{(n_a + n_b)^2}(\overline{X_a} - \overline{X_b})^2$ - разброс между группами
