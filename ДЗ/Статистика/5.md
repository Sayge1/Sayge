## Задача 1

А. Среднее арифметическое:
$\overline{X} = \frac{1}{n}\sum_{i=1}^{n}x_i$
$\overline{X} = \frac{1+3+4+7+10}{5} = \frac{25}{5} = 5.000000$
Медиана: 4
Дисперсия:
$V_X = \frac{\sum_{i=1}^{n}(x_i-\overline{X})^2}{n}$
$V_X = \frac{(1-5)^2+(3-5)^2+(4-5)^2+(7-5)^2+(10-5)^2}{5} = \frac{50}{5} = 10.000000$
Стандартное отклонение:
$\delta_X = \sqrt{V_X} = \sqrt{10} = 3.162278$
```python
import numpy as np

arr = np.array([1, 3, 4, 7, 10])

print(arr.mean())
print(np.median(arr))
print(arr.var())
print(arr.std())
```

Б. $i = 1 + (n-1)q$
$i = 1 + (5-1)\cdot0.1 = 1.4$
$Q_{0.1} = 1 + (1.4-1)(3-1) = 1.800000$
$i = 1 + (5-1)\cdot0.9 = 4.6$
$Q_{0.9} = 7 + (4.6-4)(10-7) = 8.800000$

## Задача 5

А. map сопоставляет каждому жанру его сокращение и записывает результат в новую колонку short

```python
genre_codes = {'Fantasy': 'F', 'Adventure': 'A', 'Drama': 'D'}
df_tickets['short'] = df_tickets['genre'].map(genre_codes)
print(df_tickets[['client', 'genre', 'short']])
```

Б. dropna(subset=['price']) удаляет строки, в которых отсутствует цена билета

В. С помощью groupby строки группируются по жанру. Для каждой группы считается средняя цена билета и количество покупок.

```python
grouped = df_clean.groupby('genre').agg(
    avg_price=('price', 'mean'),
    orders=('price', 'count')
).round(2)
print(grouped)
```
```text
           avg_price  orders
genre                       
Adventure      150.0       1
Drama          120.0       1
Fantasy        300.0       2
```

Г. pivot_table создаёт таблицу, где строками являются клиенты, столбцами - жанры, а значением на пересечении становится средняя цена билета, а отсутствующие комбинации заменяются на 0

```python
pivot = pd.pivot_table(
    df_clean,
    values='price',
    index='client',
    columns='genre',
    aggfunc='mean',
    fill_value=0
)
print(pivot)
```

