## Задание 1

А. $\frac{1}{n}\sum_{i=1}^{n}(aX_i + bY_i) = \frac{1}{n}\sum_{i=1}^{n}aX_i + \frac{1}{n}\sum_{i=1}^{n}aY_i = a\overline{X} + b\overline{Y}$ 
Б. $\frac{1}{n}\sum_{i=1}^{n}(aX_i + \overline{aX})= \frac{1}{n}\sum_{i=1}^{n}(a^2X_i^2 - 2aX_i\overline{aX} + \overline{aX}^2) =$
$= \frac{1}{n}\sum_{i=1}^{n}a^2X_i^2 - \frac{1}{n}\sum_{i=1}^{n}2aX_i\overline{aX} + \frac{1}{n}\sum_{i=1}^{n}\overline{aX}^2 =$
$= \overline{a^2X_i^2} - 2\overline{aX}^2 + \overline{aX}^2 = \overline{a^2X_i^2} - \overline{aX}^2$
В. $\frac{1}{n}\sum_{i=1}^{n}((aX_i - a\overline{X})(bY_i - b\overline{Y})) = \frac{1}{n}\sum_{i=1}^{n}a(X_i-\overline{X})b(Y_i-\overline{Y}) =$
$= \frac{ab}{n}\sum_{i=1}^{n}(X_iY_i - X_i\overline{Y}-\overline{X}Y_i + \overline{X}\overline{Y}) = ab(\overline{XY} - \overline{X}\overline{Y} - \overline{X}\overline{Y} + \overline{X}\overline{Y}) =$
$= ab(\overline{XY} - \overline{X}\overline{Y})$

## Задание 2

А. $F_i = 1.8T_i + 32$
$\overline{F} = \frac{1}{n}\sum_{i=1}^{n}(1.8T_i + 32) = \frac{1.8}{n}\sum_{i=1}^{n}T_i + \frac{1}{n}\sum_{i=1}^{n}32 = 1.8\overline{T} + 32$
Б. $\frac{1}{n}\sum_{i=1}^{n}(X_i + \overline{X})^2 = \frac{1}{n}\sum_{i=1}^{n}(1.8T_i + 32 - (1.8\overline{T} + 32))^2 =$
$= \frac{1}{n}\sum_{i=1}^{n}(1.8T_i - 1.8\overline{T})^2 = \frac{3.24}{n}\sum_{i=1}^{n}(T_i - \overline{T})^2 = \frac{3.24}{n}\sum_{i=1}^{n}(T_i^2 - 2T_i\overline{T} + \overline{T}^2) =$
$= 3.24\overline{T^2} - 3.24\overline{T}^2$
В. $3.24\overline{T^2} - 3.24\overline{T}^2 = 3.24 * 10 - 3.24 * 3^2 = 32.4 - 29.16 = 3.24$
