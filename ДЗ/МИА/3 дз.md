## Задача 2

А. Рассмотрим 3 вектора $v_1,v_2,v_3 \in R^3$ и их линейную оболочку $V = span(v_1;v_2;v_3)$. Возможны следующие варианты:
1. все векторы нулевые, тогда V = {0} и $dim(V) = 0$
2. Хотя бы один из векторов не равен нулю, и все вектора коллинеарны: $v_1 || v_2 || v_3$ . Тогда размерность равна 1 и каждый из ненулевых векторов является базисом V
3. $v_1$ и $v_2$ линейно независимы, а $v_3$ лежит в их линейной оболочке: $v_3 = \alpha v_1 + \alpha v_2$ . Тогда размерность равна двум и любая пара неколлинеарных векторов является является базисом
4. векторы $v_1,v_2,v_3$ линейно независимы. Тогда размерность равна 3 ($V = R^3$) и тройка векторов является базисом
Красная точка - $dim=0$
Синий вектор - $dim=1$
Зеленая плоскость - $dim=2$
Весь куб - $dim=3$

## Задача 5

Чтобы проверить что множество является подпространством нужно сделать 3 проверки: подставить нулевой вектор, проверить сложение, проверить умножение
А. $a + b = c + d$
$0 + 0 = 0 + 0$ - выполняется
Пусть $x = (a_1,b_1,c_1,d_1)$
$y = (a_2,b_2,c_2,d_2)$
x и y лежат в множестве
$a_1 + b_1 = c_1 + d_1$
$a_2 + b_2 = c_2 + d_2$
$(a_1 + a_2) + (b_1 + b_2) = (c_1 + c_2) + (d_1 + d_2)$
равенство выполняется
домножим на $\lambda$
$\lambda a + \lambda b = \lambda c + \lambda d$
неравенство выполняется
Ответ: это линейное подпространство
Б. $a + b = 1$
подставим нулевой вектор
$0 + 0 = 1$ - равенство не выполняется
Ответ: это не линейное подпространство
В. $a^2 = b^2$
подставим нулевой вектор
$0 = 0$
Пусть $x = (1,1,0,0)$
$y = (1,-1,0,0)$
x и y лежат в множестве ($1^2 = 1^2$ и $1^2 = (-1)^2$)
$x + y = (2,0,0,0)$
$2^2 = 0$ - равенство не выполняется
Ответ: это не линейное подпространство
