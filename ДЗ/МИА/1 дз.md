## Задача 2

$a = \begin{bmatrix} 0 \\ 2 \\ -1 \end{bmatrix} b = \begin{bmatrix} 1 \\ 2 \\ 4 \end{bmatrix} c = ?$
$\langle a, c \rangle = 0$ 
$\langle b, c \rangle = 0$ 
$2c_2 - c_3 = 0$
$c_1 + 2c_2 + 4c_3 = 0$
Вычтем первое уравнение из второго
$c_1 + 5c_3 = 0$
$c_1 = -5c_3$
$c_3 = 2c_2$
$c_1 = -10c_2$
Возьмём $c_1$ как -10, тогда $c_2 = 1, c_3 = 2$
Ответ: $\begin{bmatrix} -10 \\ 1 \\ 2 \end{bmatrix}$

## Задача 3

А. $a_1w_1 + a_2w_2; a \in \mathbf{R}$
Если $w_1$ и $w_2$ лежали бы на одной прямой - то векторы полученные с помощью выражения $a_1w_1+a_2w_2$ также лежали бы на одной прямой. Но так как они не лежат на одной прямой - мы можем получить любую точку
![[Снимок экрана_20260909_220531.png]]

Б. Выпуклая комбинация двух точек находится на отрезке между ними:
$aw_1 + (1-a)w_2; a \in [0, 1]$
Подставим 0:
$0 * w_1 + 1 * w_2$
$w_2$
Подставим 1:
$1 * w_1 + 0 * w_2$
$w_1$
Подставим 0.5:
$0.5 * w_1 + 0.5 * w_2$
Т.е. точка лежит посередине отрезка между $w_1$ и $w_2$ 
![[Снимок экрана_20260909_223441.png]]

В. $u_1 = \begin{bmatrix} 3 \\ 2 \end{bmatrix} u_2 = \begin{bmatrix} 6 \\ 4 \end{bmatrix}$
$u_2$ и $u_1$ лежат на одной прямой (т.к $u_2 = 2\begin{bmatrix} 3 \\ 2 \end{bmatrix}$), соответственно $u_2 = 2u_1$.
$a_1u_1 + 2a_2u_1$
$(a_1 + 2a_2)u_1$
пусть $a_1 + 2a_2 = t$, тогда
$(a_1 + 2a_2)u_1 = tu_1$
Соответственно при любом $a_1$ и $a_2$ новые вектора будут лежать на одной прямой

## Задача 7

Так как сумма координат каждого вектора равна 1, и $a + b + c = \begin{bmatrix} 1 \\ ... \\ 1 \end{bmatrix} \implies n = 3$  
Соответственно $a + b + c = \begin{bmatrix} 1 \\ 1 \\ 1 \end{bmatrix}$
$||a + b + c||^2 = 3$
$\langle a + b + c, a + b + c \rangle = 3$
$3 = \langle a, a \rangle +  \langle a, b \rangle + \langle a, c \rangle + \langle b, a \rangle +  \langle b, b \rangle + \langle b, c \rangle + \langle c, a \rangle +  \langle c, b \rangle + \langle c, c \rangle$
$3 = ||a||^2 + ||b||^2 + ||c||^2 + \langle a, b \rangle + \langle a, c \rangle + \langle b, a \rangle + \langle b, c \rangle + \langle c, b \rangle + \langle c, a \rangle$
$3 = ||a||^2 + ||b||^2 + ||c||^2 + 2(\langle a, b \rangle + \langle b, c \rangle + \langle c, a \rangle)$
$3 = 9 + 16 + 25 + 2(\langle a, b \rangle + \langle b, c \rangle + \langle c, a \rangle)$
$-47 = 2(\langle a, b \rangle + \langle b, c \rangle + \langle c, a \rangle)$
$\langle a, b \rangle + \langle b, c \rangle + \langle c, a \rangle = -\frac{47}{2}$
Ответ: $-\frac{47}{2}$
