## Задание 1

А. Фирма работает на рынке несовершенной конкуренции, так как цена зависит от количества проданной продукции. То есть фирма может влиять на цену изменяя объём выпуска, а при совершенной конкуренции фирма была бы ценополучателем и принимала бы цену рынка как данность.

Б. $P = 66 - 4Q$
$TR = P * Q = (66 - 4Q)Q = 66Q - 4Q^2$
$MR = TR' = 66 - 8Q$
$MC = 14 + 5Q$
Для максимальной прибыли $MR = MC$:
$66 - 8Q = 14 + 5Q$
$52 = 13Q$
$Q = 4$
$P = 66 - 4 * 4 = 50$
Ответ: фирме надо произвести 4 единицы продукции и продать их по цене 50.

## Задание 2

А. $Q = 750$
$P = 10$
$VC = 3750$
Площадь выделенного прямоугольника равна разнице между ATC и AVC умноженной на Q, то есть постоянным издержкам.
$FC = 1500$
$TC = VC + FC = 3750 + 1500 = 5250$
$TR = P * Q = 10 * 750 = 7500$
$\pi = TR - TC = 7500 - 5250 = 2250$
Ответ: $FC = 1500$, $TC = 5250$, $TR = 7500$, $\pi = 2250$

Б. $AVC = \frac{VC}{Q} = \frac{3750}{750} = 5$
$ATC = \frac{TC}{Q} = \frac{5250}{750} = 7$
Ответ: верхний знак вопроса - 7, нижний - 5.

## Задание 3

А. $25.52\% + 14,68\% + 10.22\% + 8.5\% + 5.16\% + 4.98\% + 3.93\% + 3.82\% + 2.73\% = 79.54\%$ - доля основных компаний
$100 - 79.54 - 7.45 = 13.01\%$ - приходится на 8 компаний
$13.01 / 8 = 1.626\%$ - примерно на каждую из 8 компаний

$HHI_1 = 8 * 1.626^2 = 21.16$
$HHI_2 = 25.52^2 + 14.68^2 + ... + 2.73^2 = 1132.39$
$HHI = HHI_1 + HHI_2 = 1132.39 + 21.16 = 1153.55$ - HHI основных компаний + 8 более маленьких.
Полный HHI объективно посчитать нельзя, так как не дано количество компаний, между которыми 7.45% распределены.
Ответ: HHI примерно 1154+, рынок умеренно концентрированный

Б. Доля Трансаэро делится пополам:
$14.68 / 2 = 7.34\%$
$S_{Аэрофлот} = 25.52 + 7.34 = 32.86\%$
$S_{ЮТэйр} = 10.22 + 7.34 = 17.56\%$

$\Delta HHI = 32.86^2 + 17.56^2 - 25.52^2 - 10.22^2 - 14.68^2 = 416.91$
Ответ: HHI увеличится примерно на 417 пунктов, то есть станет примерно 1570-1578.

Из-за этого рынок станет более концентрированным, а рыночная власть Аэрофлота и ЮТэйра вырастет. Конкуренция снизится, поэтому компании смогут сильнее влиять на цены, из-за чего цены могут вырасти, а количество перевозок снизиться. Соответственно общественное благосостояние скорее всего уменьшится. При этом если увеличение масштаба позволит компаниям снизить издержки, это может частично компенсировать отрицательный эффект.

В. Рынок авиаперевозок скорее является олигополией. На рынке есть несколько крупных компаний с большими долями, а вход на рынок требует больших затрат, самолётов, инфраструктуры и разрешений. Из-за этого у крупных авиакомпаний есть заметная рыночная власть, а действия одной крупной компании могут влиять на остальных.

Г. Если для роста прибыли компании нужно уменьшить количество пассажиров, значит при текущем объёме $MC > MR$. Последние пассажиры приносят компании меньше дополнительной выручки, чем создают дополнительных издержек, поэтому уменьшение объёма увеличит прибыль. Компания будет уменьшать количество пассажиров до точки где $MR = MC$.

## Задание 4

А. $TC(Q) = 0.75Q^2 + 4Q + 8$
$Q = 32 - P$
$P = 32 - Q$
$TR = P * Q = (32 - Q)Q = 32Q - Q^2$
$MR = TR' = 32 - 2Q$
$MC = TC' = 1.5Q + 4$
Для максимальной прибыли $MR = MC$:
$32 - 2Q = 1.5Q + 4$
$28 = 3.5Q$
$Q = 8$
$P = 32 - 8 = 24$
$TR = 24 * 8 = 192$
$TC = 0.75 * 8^2 + 4 * 8 + 8 = 48 + 32 + 8 = 88$
$\pi = TR - TC = 192 - 88 = 104$
Ответ: $Q = 8$, $P = 24$, $\pi = 104$

Б. $MC(8) = 1.5 * 8 + 4 = 16$
$L = \frac{P - MC}{P}$
$L = \frac{24 - 16}{24} = \frac{8}{24} = \frac{1}{3} \approx 0.33$
Ответ: индекс Лернера равен примерно 0.33, то есть степень монопольной власти фирмы - 33%.
