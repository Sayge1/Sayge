## Задание 1

Функция спроса:
$Q^d(P) = 200 - 2P$

Функция предложения:
$Q^s(P) = 3P - 50$

А. $Q^d = Q^s$
$200 - 2P = 3P - 50$
$5P = 250$
$P = 50$  - равновесная цена
$Q^s(50) = 3 * 50 - 50 = 100$ - равновесный объем продаж

Б. $Q^d(40) = 200 - 2 * 40 = 120$ - нова величина спроса
$Q^s(40) = 3 * 40 - 50 = 70$ - новая величина предложения
$min(Q^d(40), Q^s(40)) = 70$ - новый фактический объем продаж

## Задание 4

$Q^d(P) = a - bP$
$Q^s(P) = cP - d$
Равновесная цена и объем продаж: $P^e=50, Q^e = 100$
$Q^d(45) = 150$
$Q^s(30) = 0$

Начнём с поиска параметров $Q^s$:
$50c - d = 100$
$30c-d=0$
$d = 30c$
$20c = 100$
$c=5$
$d = 150$
$Q^s(P)=5P - 150$

Найдём параметры $Q^d$:
Подставим $P=45$ в $Q^s(P)$:
$Q^s(45)=5 * 45 - 150 = 75$
Избыточный спрос $50$, значит $Q^d(45) = 125$
$a - 50b = 100$
$a - 45b = 125$
$-5b = -25$
$b=5$
$a - 50 * 5 = 100$
$a = 350$

Ответ: $a = 350, b = 5, c = 5, d =150$
