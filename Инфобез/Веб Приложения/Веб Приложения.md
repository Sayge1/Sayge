Анализ веба:
ffuf -w путь к файлу txt с адресами -u сайт/FUZZ -fc 403 - анализирует есть ли пути из файла на сайте
-recursion - рекурсивно запускает поиск во всех найденных поддиректориях
-e текст - добавляет текст в конец каждой строчки из перебора, можно использовать для поиска файлов с определённым расширением
-fs размер ответа в байтах - позволяет игнорировать ответы определённой длины(например если сайт вместо ошибки поиска перекидывает на страницу not found)
ffuf -w ~/wordlists/parameters.txt -u http://ffuf.me/cd/param/data?FUZZ=1 - такое форматирование позволит узнать неизвестный параметр который сайт ожидает(как в задании с q в запросе на тизере alfa ctf)
ffuf -w ~/wordlists/common.txt -t 5 -p 0.1 -u http://ffuf.test/cd/rate/FUZZ -mc 200,429 - для сайтов с ограниченными запросами в секунду( -mc показывает только запросы с определёнными статусами http, -t запускает параллельные ffuf, а -p определяет задержку между запросами в секундах)
