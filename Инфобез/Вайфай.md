
> [!NOTE] Основные команды
> sudo airmon-ng check kill - убить все процессы которые могут вернуть карту из режима монитора
> sudo airmon-ng start wlan0mon - перевод в режим мониторинга
> sudo airodump -i wlan0mon -d BSSID -c CH - отсмотр отдельной сети
> sudo aireplay-ng -a BSSID --deauth "количество пакетов" wlan0mon - отсылка пакетов для деауентификации
> sudo airodump-ng -i wlan0mon - отсмотр всех сетей
> sudo aircrack-ng -b BSSID pca/ivs файл -w словарь_паролей.txt - брут пароля по словарю

> [!NOTE] Bettercap
> sudo bettercap --iface wlan0mon - запуска беттеркапа
