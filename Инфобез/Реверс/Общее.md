## IDA Pro

n - переименовать переменную
/ - написать комментарий (если комментарий будет пустой - появится пустая строка)
shift + * - сделать из переменной массив (например изменить из одного char на char[256])
y - поменять декларацию функции (или изменить тип переменной)
shift + f12 - открыть окно со всеми строками в программе
x - находит все перекрёстные ссылки с этим элементом, т. е. где он ещё встречается в программе
h - переключение представления числа (например 0x100u в 256u)

## Указатели

x - возвращает значение переменной
&x - возвращает адрес переменной
int `*p` = &x - указатель p хранит адрес переменной x
p - вернёт адрес переменной x
`*p` - вернёт значение по адресу
