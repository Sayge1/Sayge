chr() - переводит ASCII значение знака в знак
ord() - переводит знак в его ASCII значение

bytes.hex() - представляет байтовую строку в шестнадцатеричном (hex) виде
bytes.fromhex() - переводит шестнадцатеричное (hex) представление строки обратно (строка будет в виде байтов, например b'crypto{3nc0d1n6_4ll_7h3_w4y_d0wn}')

строка.encode() - делает представление строки в байтах, нужно для кодировки строки например в base64
bytes(объект) - делает из строки byte-array
bytes(объект).decode()  - вернёт объект в изначальном виде
.encode() только для строк, bytes() для всего

base64.b64encode() - кодирует байты в base64 (для начала надо сделать import base64)
base64.b64decode() - переводит base64 обратно

bin() - переводит десятичное число в двоичное
pow(1 число, 2 число, модуль ответа)

Представление в разных системах:
"4" <=> 54(DEC = ASCII) <=> 34(HEX = BYTES)
4(DEC) <=> 4(HEX, получаем делением dec) <=> 100(BIN, получаем делением) 
A(ASCII код символа) - ord("a") - преобразование ASCII кода символа в его позицию в алфавите
